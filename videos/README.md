# Vídeos do ICEIBank

As três sprints estão disponíveis separadamente e reunidas no vídeo completo. Todos os arquivos estão em 0,5× e contêm legendas incorporadas, com o trecho do código responsável ao lado do fluxo.

- [Completo](ICEIBank-3-sprints-0.5x.mp4)
- [Sprint 1](ICEIBank-sprint-1-0.5x.mp4)
- [Sprint 2](ICEIBank-sprint-2-0.5x.mp4)
- [Sprint 3](ICEIBank-sprint-3-0.5x.mp4)

Baixe os arquivos MP4 para reproduzir no computador. O reprodutor oferece os controles de pausa e navegação e, quando disponível, o ajuste de velocidade. Como a redução já está aplicada ao arquivo, 1× reproduz em metade do ritmo da gravação; 2× volta ao ritmo original.

Os arquivos foram separados pelos limites dos capítulos, sem misturar sprints. A redução de velocidade altera os tempos de reprodução, preservando os quadros da gravação e a qualidade da imagem. Os vídeos não possuem áudio. O mobile foi demonstrado com Flutter Web, sem validação Android nativa.
